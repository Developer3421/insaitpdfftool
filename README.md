# insaitpdfftool

A Next.js client-side PDF merger and splitter with B2 Step Further style UI.

## Features

- **Merge PDFs** — Combine multiple PDF files into one, reorder pages before merging
- **Split PDF** — Extract individual pages, page ranges, or custom page selections
- **100% client-side** — All PDF processing happens in the browser using [pdf-lib](https://pdf-lib.js.org/). No files are uploaded to any server.
- **B2 Step Further** UI — Bold, numbered step-by-step workflow design

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [pdf-lib](https://pdf-lib.js.org/) — client-side PDF manipulation
- [Tailwind CSS](https://tailwindcss.com/) — styling
- TypeScript
